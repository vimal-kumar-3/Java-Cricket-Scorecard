# Java Cricket Scorecard

A console-based cricket match simulation developed using Java.

## Features
- Select two teams and their Playing XI
- Conduct the toss and choose batting or bowling
- Configure the number of overs
- Update scores ball by ball
- Track batter runs, balls faced, fours, sixes, and strike rate
- Display bowler overs, runs conceded, wickets, and economy
- Display the final scorecard and match result

## Technologies Used
- Java
- Object-Oriented Programming (OOP), if used in the implementation

## How to Run
1. Clone or download this repository.
2. Open the project in IntelliJ IDEA or another Java IDE.
3. Compile and run the main Java class.
4. Follow the console prompts to simulate a match.
